# Keyboard Layout OSD

DMS plugin for niri. Open DMS Settings → Plugins, scan for plugins, enable
Keyboard Layout OSD, and use its settings to adjust the popup. It uses DMS's
existing niri connection, so no extra niri autostart command is needed.

After reinstalling, restore this directory to
`~/.config/DankMaterialShell/plugins/KeyboardLayoutOSD/` and restart DMS.
Your chosen settings are stored separately under `keyboardLayoutOSD` in
`~/.config/DankMaterialShell/plugin_settings.json`; back up that file too.
